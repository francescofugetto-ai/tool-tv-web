# Tool TV

**https://francescofugetto-ai.github.io/tool-tv-web/**

Questo repository contiene soltanto il documento consegnato di **Tool TV**
(TV monomorfa e QRS largo in acuto), servito da GitHub Pages. Esiste per l'iPhone: li' un file HTML
salvato sul telefono si apre nell'anteprima, che non esegue JavaScript, mentre
da questo indirizzo il tool funziona, si aggiunge alla schermata Home e dopo la
prima apertura funziona anche senza rete.

La sorgente sta altrove e questo repository si aggiorna solo da li', con
`scripts/pubblica_tool.py`. **Non modificare i file qui**: la pubblicazione
successiva li sovrascrive.

Materiale di consultazione: non sostituisce il giudizio clinico, i protocolli di
reparto ne' le linee guida.

Creato dal dott. Francesco Fugetto.
